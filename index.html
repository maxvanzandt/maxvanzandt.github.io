About

I am finishing an MA in Statistics and Data Science at UC Berkeley, where my coursework is built around causal inference, experimentation, and nonparametric methods. I want to work where the statistics is load bearing for the business rather than decorative, which in practice means product data science or biostatistics.

Before Berkeley I finished a BS in Statistics at UVA with a minor in philosophy, mostly analytic moral philosophy. The philosophy shows up more than you would expect: two of the projects below started as an argument I wanted to test by building it.

I have built survival models on satellite IoT and aviation data at Iridium, led a consulting team serving healthcare nonprofits at Biokind Analytics, led UVA's NFL Big Data Bowl entry through the Sports Analytics and Statistics Laboratory, and taught statistics as a TA.

Away from the desk I have played percussion for fifteen years. I lead a band that has opened for Neon Trees and releases music on Spotify, and I am an Eagle Scout.

Projects

Code and write ups live in their own repositories. The interactive pieces run live, so you can push on the analysis instead of reading my conclusions.

  1. 2026 Capstone, STAT 4996

    Album Covers and Billboard Success

    Predicts Billboard 200 chart performance from the visual features of album cover art. The pipeline collects covers and chart data, engineers color and composition features from the images, then fits supervised models against chart outcomes. Built with a team of four.

    • Python
    • scikit-learn
    • computer vision
    • APIs

  2. 2025 Course project

    Kernel CCA for Market Analysis

    Applies kernel canonical correlation analysis to nine macroeconomic and market series from FRED, looking for nonlinear association that linear methods miss. A linear CCA baseline with a Wilks' Lambda test runs first, so the kernel extension has something to beat.

    • R
    • kernel methods
    • FRED

    Repository

  3. 2025 Interactive

    The Evolution of Virginia Lacrosse

    Follows five seasons of UVA men's lacrosse through a change in offensive coordinator, using goal differential, shooting and extra man efficiency, the distribution of scoring across players, and hustle metrics. Filter by conference and metric to check the argument yourself.

    • R
    • Shiny
    • plotly
    • ggplot2

    Run it live Repository

  4. 2025 Interactive

    Publication Bias Simulation

    Turns an argument from the philosopher Liam Kofi Bright into a working model. If journals reward significant findings, what does the published record look like next to the research that was actually conducted? The publication model follows Moss and De Bin (2021). It illustrates a mechanism rather than estimating real publication rates.

    • R
    • Shiny
    • simulation

    Run it live Repository

  5. 2025 Interactive

    P-Hacking Under Publication Pressure

    A companion piece where you play the researcher. Pick an analysis strategy, set the publication pressure, and watch significance appear when the true effect is exactly zero. The p-hacking model also follows Moss and De Bin (2021).

    • R
    • Shiny
    • simulation

    Run it live Repository

  6. 2025 Course project

    Drumming Styles: A Distributional Feature Analysis

    Compares the distributional signatures of drumming styles using the Groove MIDI Dataset, extracting timing and velocity features from roughly 1,150 recorded performances. Fifteen years behind a kit turned out to be useful for feature design.

    • Python
    • R
    • MIDI

    Repository

  7. 2024 Course project

    Statewide Mortality and Medicaid

    Looks at the relationship between state Medicaid policy and mortality outcomes using FRED, CDC, KFF, and Census data. Cleaning is separated from analysis so the whole thing can be rerun from raw sources.

    • R
    • public health data
